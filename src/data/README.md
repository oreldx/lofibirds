# Catalogue et ressources

Le catalogue contient les cinq espèces. Les tableaux audio vides et les sprites
à null indiquent des ressources encore absentes ; aucun fichier fictif n’est chargé.

Avant toute intégration, vérifier et renseigner l’auteur, la source, la licence,
le lien vers la licence et les modifications (tableau vide si aucune).
Importer les fichiers locaux via Vite et associer leurs crédits dans le catalogue.

Le décor et l’ambiance seront également des ressources créditées. Le fichier
garden.png à la racine reste hors du build en attendant la vérification de sa provenance.
